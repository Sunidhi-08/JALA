Table layout

ModeHow the browser sizes columnsExample content
Automatic (default)Column widths respond to cell content.A naturally wider sentence can take more room.
FixedColumn widths are determined from the table and first row.This longer text wraps inside its assigned column instead of resizing it.

table-layout accepts auto or fixed; none is not a valid value. The automatic mode is the default.
