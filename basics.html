02 / QUICK GUIDE

What each technology does

HTML and HTML5

HTML is the standard markup language for structuring web content. HTML5 is the modern version of that standard, with native audio, video, semantic elements, and improved form controls.

CSS and JavaScript

CSS styles and lays out the structure. JavaScript is a programming language that can respond to events, update content, and make a page interactive. They complement HTML rather than replace it.

<div> and <span>

A div is a generic block-level container, useful for grouping a section of content. A span is a generic inline container, useful for styling or identifying a small part of text, such as this phrase.
